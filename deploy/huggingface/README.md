# PaperCast

Drop in a research paper, get a podcast episode that says only what the paper
says, with every line traced back to its page.

This Space runs the project's container in demo mode: no uploads, a fixed
shelf of papers, and daily limits on both episodes and questions. The source,
the design notes and the evaluation harness are on GitHub — replace this line
with the link before pushing the Space.
