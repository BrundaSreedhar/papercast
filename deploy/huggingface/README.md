# PaperCast

Drop in a research paper, get a podcast episode that says only what the paper
says, with every line traced back to its page.

**Source: [github.com/BrundaSreedhar/papercast](https://github.com/BrundaSreedhar/papercast)**
— including the design notes and the evaluation harness.

This Space runs the project's container in demo mode: pick a paper from the
shelf or drop in your own, with daily limits on both episodes and questions so
a public link cannot run up a bill. The whole thing also runs locally for free,
voice included.
